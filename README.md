# RUNPREDICT

RUNPREDICT is a simple Python-based console application designed to help beginners practise program tracing and predict Python outputs while improving their fundamental programming skills.

## Features

* Practice Python program output prediction
* Data, expressions, and statements
* Conditional and looping statements
* Fundamental algorithms
* Lists, tuples, and dictionaries
* Factorial, Fibonacci, reverse number, summation, and GCD
* Random question generation
* Hints for difficult questions
* Answer checking and score tracking
* Input validation
* Automated testing using Python `unittest`

## Project Structure

* `main.py` – Handles user interaction and overall program flow
* `questions.py` – Generates practice questions
* `algorithms.py` – Contains basic algorithm implementations
* `validation.py` – Handles input validation and answer checking
* `progress.py` – Tracks attempts and correct answers

## How It Works

The user starts the application from the main menu and selects a practice area. A short Python program is displayed, and the user predicts its output. The application checks the answer, updates the score, and provides a hint when required.

## Testing

The project uses Python's built-in `unittest` framework to test algorithms, validation, answer comparison, and progress tracking.

## Purpose

RUNPREDICT provides a simple and practical way for CSE1021 students to strengthen logical thinking, program-tracing ability, and basic Python programming skills.
