# RUNPREDICT - Project Statement

## 1. Project Title

**RUNPREDICT: A Simple Python Program Output Predictor**

## 2. Problem Statement

Students learning introductory programming may understand individual statements but still find it difficult to follow the value of variables through a complete program. RUNPREDICT addresses this problem by giving short Python programs and asking the student to predict the output before seeing the answer.

## 3. Objectives

- Improve step-by-step program tracing.
- Practise variables, expressions and statements.
- Practise conditional and looping statements.
- Practise fundamental algorithms such as factorial, Fibonacci, reverse and GCD.
- Practise lists, tuples, sets and dictionaries.
- Encourage logical problem solving rather than memorising outputs.

## 4. Target Users

The primary users are students studying CSE1021 Introduction to Problem Solving and Programming.

## 5. Scope

The project is a console-based learning application. It covers selected CSE1021 programming concepts through small output-prediction exercises. It does not attempt to become a general online learning platform.

## 6. Three Major Functional Modules

### Module 1 - Topic Selection
The user selects one of four practice areas.

### Module 2 - Practice and Answer Checking
The program displays a short Python program, accepts the student's predicted output, and compares it with the expected output.

### Module 3 - Progress and Results
The program records the number of attempts and correct answers during the current session and displays a final result.

## 7. Input and Output

**Input:** menu choice, predicted output, and normal console commands.

**Output:** question program, topic name, hints, correctness message, score and final result.

## 8. Workflow

Start → choose topic → receive question → read program → enter prediction → check answer → update score → continue or exit.

## 9. Syllabus Alignment

The project is aligned with CSE1021 units on problem solving, Python data/expressions/statements, control flow and functions, fundamental algorithms, factoring methods, array techniques and Python collections.

Scratch and Raptor are included in the course as tools for programming and flowcharts. They are documented as supporting design tools rather than forced into the Python application.

## 10. Deliberate Scope Limits

The implementation does not add a database, web server, GUI toolkit, external libraries, machine learning, code execution sandbox, tracing API, JSON configuration system, or unnecessary advanced Python features. This keeps the implementation appropriate for an introductory programming course.
